# IT 知识库 · 企微智能机器人（长连接版）

把 `03_知识库内容清单_定制版.csv`（84 条）挂进企业微信**智能机器人**，实现：

- 💬 **员工问答**：提问命中知识库即自动回答；答不上来引导转人工
- 🎓 **自动学习**：答不上来的问题**自动记录**成「待学习清单」，你定期批量补答案
- 🃏 **快捷问题按钮**：员工进入会话即推「高频问题」卡片，点一下直接出答案（见下方说明）
- 🔒 **唯一维护人 钟勇**（userid：`ZhongYong`）：可直接改库，改动**立即生效**
- 🃏 **他人改库需逐条审批**：任何人提交 → 机器人把**审批卡片**推给钟勇 →
  钟勇点【通过】/【驳回】按钮逐条审批，通过后才落库
- ✅ 所有对外话术显示 **钟勇**（不是 userid）
- 🚫 不涉及邮箱助理机器人

## ⚡ 快速开始（3 步）

### 第 1 步：安装

双击 **`install.bat`**（或中文名 `安装.bat`）。脚本会自动：
1. 找到或安装 Python 3.11
2. 安装依赖
3. 生成 `.env`
4. 导入 84 条知识库

看到 `Install finished successfully!` 即可。

### 第 2 步：填写 `.env`

用**记事本**打开 `.env`，填上从企微后台拿到的两个值：

```ini
WECOM_BOT_ID=你的BotID
WECOM_BOT_SECRET=你的Secret
KB_MAINTAINER_ID=ZhongYong
KB_MAINTAINER_NAME=钟勇
KB_MOCK=0
```

> 保存时**编码选 UTF-8**；等号两边不要空格；不要加引号。

### 第 3 步：先自检，再启动

**① 双击 `check.bat`（自检，强烈推荐）**

它会逐项检查 Python、依赖、`.env`、知识库、订阅，然后**进入 120 秒监听**。
监听期间请在企业微信里给机器人发一条消息（如 `你好`）。

- 看到 `MESSAGE RECEIVED!` → **通道正常**，可以去启动
- 看到 `NO MESSAGE RECEIVED` → 消息通道不通，看下面的排查章节

**② 双击 `start.bat` 启动**（手动运行，窗口要开着）

看到 `[bot] 已连接并订阅成功` 即上线。**窗口保持开着** —— 关掉就停了。

### 第 4 步（推荐）：设置开机自启 🔁

> **如果电脑会重启、关机，一定要做这步**，否则机器人不会自己回来。

双击 **`setup_autostart.bat`**，看到 `DONE` 即可。之后：

- 电脑**开机登录后自动启动**，不用你管
- 进程**意外退出会自动重启**（内置 10 秒冷却）
- 日志写到 `logs\bot-YYYYMMDD.log`（按天分文件）

配套脚本：

| 脚本 | 作用 |
|---|---|
| `setup_autostart.bat` | 安装自启（开机登录时拉起） |
| `check_status.bat` | 看任务状态 + 进程 + 最近日志 |
| `remove_autostart.bat` | 取消自启 |

> ⚠️ **注意**：`run_service.bat` 是给计划任务调用的**后台运行器**，**别双击它**
> （它没有暂停、会无限重启循环，双击会看着"卡住"）

- 计划任务用的是 `ONLOGON`（登录时启动）—— 因为它要读写你用户目录下的
  Python 和 `.env`，用系统 `ONSTART` 反而容易因权限找不到文件
- 想更彻底（没登录也跑），见下方「进阶」

<details>
<summary><b>进阶：没登录也要跑 / 开机就跑</b></summary>

默认用 `ONLOGON` 是因为最稳。若你的机器是"开机后无人登录"的服务器，
需要用 `ONSTART` + 指定运行账户：

```bat
schtasks /Create /TN "IT_KB_Bot" /TR "\"C:\完整路径\机器人服务\run_service.bat\"" ^
    /SC ONSTART /RU "你的用户名" /RP "你的密码" /RL HIGHEST /F
```

⚠️ 两个坑：
1. **路径必须用绝对路径**，`ONSTART` 不会继承当前目录
2. `ONSTART` 用系统账户跑时，可能找不到 `%LOCALAPPDATA%` 下的 Python；
   建议在 Python 装到 `C:\Python311` 这类全局路径，再改 `run_service.bat`

</details>

### 第 5 步：以后怎么更新 🔁

有两种方式，**推荐第二种（更省事）**：

#### 方式一：双击 `更新.bat`（本地，随时可用）

1. 把我给你的新升级包 `.zip` 放进**收件文件夹**
   （默认是 **`F:\KIDE_BOT_update`**，第一次运行会自动创建。想换位置见下方"自定义收件夹"）
2. 双击 **`更新.bat`**
3. 完事 —— 它自动：

```
[1/6] 停掉正在跑的服务
[2/6] 备份当前版本到 _backup\时间戳\
[3/6] 解压新升级包
[4/6] 覆盖代码（app / tools / tests / *.bat / *.md）
      ★ .env（你的凭据）和 data\（kb.csv、owners…）原样保留，绝不覆盖
[5/6] 清理缓存
[6/6] 重启服务
```

**为什么不会丢数据**：脚本**只覆盖程序代码**，你的
`.env`（机器人密钥）和 `data\`（知识库内容、目录负责人、审批记录）**一个字节都不动**。

**出错了怎么回滚**：脚本每次都会把旧版本备份到 `_backup\时间戳\`，
把里面的 `app\` 和 `*.bat` 拷回去即可还原。

**自定义收件夹**（可选）：默认就是 `F:\KIDE_BOT_update`，一般**不用改**。
若确实要换位置，把新路径写进服务目录下的 `update_dir.txt`（一行，一个路径，
参考 `update_dir.txt.example`），或运行前设环境变量 `KB_UPDATE_DIR`。

> 💡 **只改知识内容**（加问题/改答案）**根本不需要更新程序** —— 在企微里用
> `/ai` 或 `/import` 就行，改完立即生效。`更新.bat` 只用于**我发布了新功能**的时候。

#### 方式二：企微里发 `/update`（推荐，不用碰电脑）

配好**更新源**后，机器人能自己拉新版：

```
钟勇> /update
🤖 🚀 发现新版本 1.1.0（当前 1.0.0），开始升级…
   约 5 秒后服务会重启，重启期间机器人短暂离线，属正常现象。

（服务自动重启，跑的就是新版本）
```

- `/update check` —— **只看不升**，先看有没有新版
- `/version` —— 随时查当前版本
- 只有**钟勇**能用 `/update`

**怎么配更新源**（`.env`，三选一）：

```ini
# ① 公网网址（推荐）：指到一个 .zip 直链
KB_UPDATE_URL=http://你的公网地址/kb/latest.zip

# ② Git 仓库（进阶）
KB_UPDATE_GIT=https://gitee.com/你/it-kb-bot.git
KB_UPDATE_GIT_BRANCH=main

# ③ 本地目录（默认，取目录里最新的 .zip）
KB_UPDATE_DIR=F:\KIDE_BOT_update
```

**它是怎么重启自己的**：机器人**不能直接自杀重启**（进程杀了就没了）。
所以用**两段式**：先回你"开始升级"→ 3 秒后覆盖代码 → 退出（退出码 42）→
**你配的"开机自启计划任务"把它重新拉起**，跑的就是新版本。

> ⚠️ **前提**：必须先做过「第 4 步：设置开机自启」，否则升级后没人把它拉起来。

**公网更新源怎么搭**：见交付目录的 **`08_公网更新源_部署指南.md`**
（针对 Windows 11 专业版，含 nginx / python / IIS 三种做法 + 安全建议）。

#### 方式三：**全自动升级（零操作）** ⭐ 最省事

配好**公网 Git 公开仓库**后，机器人**每 10 分钟自动检查**，有新版本就**自动拉取并重启** ——
**你什么都不用做**：

```ini
KB_UPDATE_GIT=https://gitee.com/你/it-kb-bot.git
KB_UPDATE_GIT_BRANCH=main
KB_AUTO_UPDATE=1
KB_AUTO_UPDATE_INTERVAL=10
```

之后：我推代码到仓库 → 最多 10 分钟后 → 你的机器人自动变成新版，
并给你发一条企微通知「✅ 自动升级完成：1.0.1 → 1.0.2」。

> ⚠️ 同样**依赖「开机自启」**（自动重启靠它）。
> 搭建步骤见 **`09_零操作自动升级_搭建指南.md`**。
> 不想公开代码？那用 Git 私有仓库 + 部署公钥（文档里有）。

**三种升级方式对比**：

| 方式 | 你要做什么 | 需要凭据 | 版本回滚 |
|---|---|---|---|
| `更新.bat` | 下载 + 双击 | 不需要 | 手动 `_backup` |
| 企微 `/update` | 传包 + 发指令 | 不需要 | 手动 `_backup` |
| **自动升级** | **零操作** | 不需要（公开仓库） | Git 历史 |

**运维侧发新版（我这边做的事）**：

```bash
bash tools/push_update.sh 1.0.1 "修复：ERP 地址变更"
```

改版本号 → 提交 → 推送一条命令搞定。推完最多 10 分钟，机器人自动升级并回企微通知。
搭建步骤见 **`10_公开仓库搭建与首推_操作指引.md`**。

## 🚨 收不到消息？按这个顺序排查

这是最容易卡住的地方。请**逐条**对照：

| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | 机器人是 **API 模式 + 长连接** 创建的吗？ | 后台看创建方式是否为「API 模式创建」→「使用长连接」 |
| 2 | Bot ID / Secret 填对了吗？复制后**点了「保存」**吗？ | 不保存会报 `errcode 853000` |
| 3 | 机器人**启用了**吗？ | 后台看状态是否有「启用/发布」按钮，有就点 |
| 4 | 消息**发给对的机器人**了吗？ | 必须从 **工作台 → 智能机器人** 点进去发，不是在聊天列表里搜 |
| 5 | 是否有**别的实例抢占**长连接？ | 同一机器人只能有一个连接。关掉其它窗口/服务器上的实例 |
| 6 | 这个机器人是不是**企业自建应用**？ | 若是，消息不走长连接，无法用本方案 |

**判断技巧**：运行 `check.bat` 期间发消息，如果始终 `NO MESSAGE RECEIVED`，
但订阅是成功的（`errcode=0`），那基本就是 **第 3/4/6 条** —— 机器人没真正启用，
或者这根本不是"API 模式长连接"机器人。

## 🎓 自动学习：从员工提问里长知识

**这是知识库会自己变强的关键机制。**

### 闭环长这样

```
① 员工问了个知识库没有的问题
   员工> 团建经费怎么报销
   🤖 抱歉，没有找到对应的答案…（同时【静默记录】进待学习清单）

② 同一个问题被多人问 -> 频次自动累加，越热越靠前
   （不问不打扰员工，员工无感）

③ 钟勇想看时，一条命令调出清单
   钟勇> /learn
   🤖 📚 待学习清单（共 3 条，按提问次数排序）：
      1. 团建经费怎么报销　（问过 5 次 / 4 人）
      2. 快递柜在哪　　　　（问过 2 次 / 2 人）
      3. 门禁卡丢了怎么办　（问过 1 次 / 1 人）

④ 挑一条补答案，走审批后入库
   钟勇> /learn 1
   🤖 📝 为这个问题补充答案：「团建经费怎么报销」（被问过 5 次）
      请输入【标准答案】
   钟勇> 在OA提报销单，选「团建经费」科目。##由钟勇审批。
   🤖 已提交，等待钟勇审批。单号 xxx（点审批卡片「通过」即入库）

⑤ 入库后该条自动从清单消失，员工再问即可命中 ✅
```

### 命令一览

| 命令 | 作用 |
|---|---|
| `/learn` | 查看待学习清单（按提问热度排序） |
| `/learn <编号>` | 给该问题补答案 → 生成审批单 → 点「通过」入库 |
| `/learn skip <编号>` | 忽略某条（不再出现，记录仍留档） |
| `/learn clear` | 清空整个清单 |

### 设计要点

- **静默记录，不打扰员工**：员工永远只看到"没找到答案"的正常引导，
  不知道自己被"记账"了
- **归一化去重**：`绘图仪怎么申请` / `绘图仪怎么申请？` 算同一条，累计频次
- **热度排序**：越多人问越靠前 —— 优先补高频问题，性价比最高
- **必须钟勇确认才入库**：学习来的知识也走**同一条审批链路**，不会自动生效
- **已补即出列**：答案入库后该问题自动移出清单，不会重复提醒
- **主动提醒**：待学习清单每攒够 5 条（可配 `KB_LEARN_REMIND_AT`），
  机器人会给钟勇推一条提醒，附 `/learn` 入口

> 记录文件在 `data/unmatched.json`，是普通 JSON，可直接查看/备份。

## 🌳 可成长的目录结构 & 目录负责人

知识库按 **三级目录** 组织，并可为**任意层级指定负责人**，让不同的人各管一摊。

```
■ 软件
  ├ 浩辰CAD许可配置
  │   · 安装部署 / 性能问题 / 模块与功能 / 激活授权
  ├ AutoCAD与Revit
  │   · 性能问题 / 文件与模型 / 显示与字体 / 激活授权 / 许可容量 / 许可故障 / 许可服务器
  ├ SketchUp            ├ 火绒安全软件          └ 软件通用问题
■ ERP
  ├ ERP登录权限         ├ ERP项目管理            └ ERP查询导出
■ 电脑故障
  ├ 系统故障            ├ 外设网络               └ 常用软件报障
```

> 一级=**类别**，二级=**分组**，三级=**细分**（对应 `kb.csv` 的
> `类别 / 分组 / 三级目录` 三列）。

### 随时用对话查看目录

| 输入 | 效果 |
|---|---|
| `/tree` | 打印**完整三级目录树**，带每层条数与负责人 |
| `/tree <目录路径>` | 列出该目录下的条目，例如 `/tree 软件/浩辰CAD许可配置` |

```
钟勇> /tree
🤖 📚 知识库目录结构（共 84 条）

   ■ 软件（41 条）　负责人 👑钟勇
     ├ 浩辰CAD许可配置（8 条）　负责人 👑钟勇
     │   · 激活授权（5 条）　负责人 👑钟勇
     │   · 安装部署（1 条）　负责人 👑钟勇
     …
```

**员工也能 `/tree`**，随时了解知识库都有哪些内容。

### 指定目录负责人

```
钟勇> /owner 软件/浩辰CAD许可配置 ZhangGong
🤖 ✅ 已把目录「软件/浩辰CAD许可配置」的负责人从 钟勇 改为 ZhangGong
```

| 输入 | 效果 |
|---|---|
| `/owner` | 查看当前各目录的负责人 |
| `/owner <目录全路径> <企微userid>` | 指定/更换负责人 |

### 权限规则（"只管自己目录，到自己为止"）

| 角色 | 权限 |
|---|---|
| **钟勇**（`ZhongYong`） | 全库最高权限，任何目录都能改、能审批 |
| **目录负责人** | **只**能改自己负责目录（含其下级）内的条目，改动**立即生效**；跨目录操作被拒 |
| **普通员工** | 只能提问；要补充内容走「提交」→ 对应目录负责人审批 |

要点：

- **越具体优先**：给三级目录配了负责人就用三级的，没配就回退到二级、再到一级、最后到钟勇
- 某目录的负责人**天然覆盖其所有子目录**（管了「软件」就管「软件」下的一切）
- 负责人自己做的 `add / edit / del` **不经审批、直接生效**（在他自己的一亩三分地内）
- 跨目录时会被明确拦下，并告诉他这条归谁管、该找谁

### 审批自动路由到对应负责人

员工「提交」时会被问一句"这条知识属于哪个目录"（不确定就回「不知道」，
交钟勇分诊）。审批卡片**只推给该目录的负责人**，不再是所有事都压给钟勇：

```
员工: 提交 → 软件/火绒安全软件/运行与防护 → 问题 → 答案
机器人 → 员工: 已提交，等待目录负责人（HuooOwner）审批。单号 4fd…
机器人 → HuoOwner: 【审批卡片】📋 知识库变更待审批
                提交人：emp1　操作：新增　目录：软件/火绒安全软件/运行与防护
                [✅通过] [❌驳回]
```

> 目录负责人的配置存在 `data/owners.json`，是普通 JSON，可直接编辑/备份。

## 🃏 关于"输入框里的按钮"

**先说结论：企微 API 模式机器人，官方不支持在输入框上方放常驻快捷按钮。**

这个能力只属于「后台配置型」机器人。查过官方 Node SDK v1.0.7 的
`EnterChatEvent` 类型——它是空的，没有任何按钮字段；机器人能发的消息只有
`markdown` / `template_card` / `stream` 三种，`action_list`（卡片右上角
"更多操作"）也只作用于**单张卡片**，不是输入框。

**本方案的等效实现：员工一进入机器人会话，就自动收到一张「高频问题」卡片。**

```
┌──────────────────────────────┐
│ 👋 我是 IT 知识库助手          │
│  点下面任意问题，我直接给答案    │
│                              │
│ [浩辰CAD怎么激活] [AUTODESK…] │
│ [ERP系统怎么登录] [打印机…]   │
│ [火绒客户端怎么安装] [电脑开不…]│
└──────────────────────────────┘
```

点任意按钮 → 卡片原地变成答案卡片。体验上等价于"快捷按钮"，只是它出现在
**会话里**而不是输入框上方。

**想改这几个问题？** 编辑 `app/cards.py` 里的 `WELCOME_QUESTIONS`（最多 6 个）：

```python
WELCOME_QUESTIONS = [
    '浩辰CAD怎么激活', 'AUTODESK CAD怎么激活', 'ERP系统怎么登录',
    '打印机连不上怎么办', '火绒客户端怎么安装', '电脑开不了机怎么办',
]
```

改完重启即可。触发时机是 `enter_chat` 事件（员工当天首次进入会话）。

## 🤖 AI 自然语言改库（推荐用法）

**这是最省事的维护方式**：不用记命令、不用选字段，**说一句话**就行。

### 怎么用

```
钟勇> /ai 把火绒怎么安装的答案改成：先访问 sf.cckide.com:6080 下载客户端，然后一路下一步
🤖 我理解你要【修改】「火绒客户端怎么安装」
   将要改成：
     · 标准答案：火绒客户端安装方法：##1. 访问 sf.cckide.com:6080 …
   
   回复「是/确认」立即生效，「否/取消」放弃。（如只想追加、不覆盖，回复「追加」）

钟勇> 是
🤖 ✅ 已修改并立即生效
```

**都能做什么：**
| 你说的 | AI 做的 |
|---|---|
| 「把XX的答案改成…」 | 修改该条答案 |
| 「给XX加一个相似问法：YY」 | 追加相似问法 |
| 「新增一条：AAA 怎么办 → 先做B再做C」 | 新增条目 |
| 「删除XX那条」 | 删除（会先让你确认） |
| 「在XX答案后面追加一句…」 | 回复「追加」保留原文 |

**也支持免打 `/ai`**：直接说「帮我改 …」「改 …」「优化 …」同样触发。

### 安全设计（重要）

- **AI 只理解 + 生成，不直接落库**：每次都会先给你**看预览**，你**点确认才写库** —— 防止 AI 幻觉污染知识库
- **遵守目录权限**：AI 改的条目若不在你负责的目录内，会被拦下（钟勇除外）
- **可取消**：回复「否」即放弃，什么都不改
- **失败有兜底**：模型调不通时明确提示，不影响其它功能

### 如何启用（重要）

AI 功能**默认关闭**，需要在服务目录的 `.env` 里配置（**任何 OpenAI 兼容服务都行**）：

```ini
AI_ENABLED=1
# 阿里云百炼（推荐，与 Qoder CN 同属阿里云）
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_API_KEY=sk-你申请到的key
AI_MODEL=qwen-plus
```

> - **阿里云百炼**：控制台 → API-KEY 管理 → 创建，拿 `sk-` 开头的一串。模型 `qwen-plus` 够用，`qwen-turbo` 更便宜。
> - **公司内部网关**：把 `AI_BASE_URL` 换成内部地址即可。
> - 配好后**重启一次服务**生效。
> - **没配 AI 也不影响** `/add` `/edit` `/del` 手动改库——功能不会因此失效。

> ⚠️ **数据安全提示**：使用 AI 改库时，你发送的内容会传给所配的模型服务。
> 若用**公司内部部署**的模型则不出内网；若用公网 SaaS（如百炼公网版），
> 内容会到该服务商。请按公司数据合规要求选择。

## 📥 批量导入（`/import`）：把表格里的多条知识一次导入

零散改动用 `/ai`，**成批更新用 `/import`** —— 适合负责人整理好一份 Excel 后整批上传。

### 为什么是"发链接/路径"而不是"直接拖文件"

> **企微平台的限制**：API 模式的智能机器人，收到用户发的文件时**只能拿到下载链接**，
> **拿不到文件正文**。所以机器人无法直接"读"你拖进来的 Excel。
> `/import` 用「发链接或服务器路径」绕开这个限制，效果一样。

### 怎么用

```
钟勇> /import https://你的网盘/浩辰新增.xlsx

📥 解析完成，共 3 条：
  · 新增 2 条
  · 修改 1 条
  · 无变化 0 条

【新增】
  + [软件/浩辰CAD许可配置/激活授权] 导入测试新增问题A
  + [ERP/登录与权限/账号] ERP账号被锁定怎么办
【修改】
  ~ 浩辰CAD怎么激活获取授权（改动：标准答案）

确认导入？回复「是」执行，「否」取消。

钟勇> 是
✅ 导入完成并立即生效：新增 2 条，修改 1 条。
```

### 表格格式

支持 **`.xlsx`** 和 **`.csv`**。表头用中文列名即可（自动识别别名）：

| 列 | 必填 | 别名示例 |
|---|---|---|
| 标准问题 | ✅ | 问题 / 标题 |
| 标准答案 | ✅ | 答案 / 内容 |
| 类别 | 否 | 一级目录 / 一级 |
| 分组 | 否 | 二级目录 / 二级 |
| 三级目录 | 否 | 三级 / 子目录 |
| 相似问法 | 否 | 相似问题 |
| 触发关键词 | 否 | 关键词 / 关键字 |
| 升级路径 | 否 | 升级 |

- 答案里用 `##` 表示换行（与知识库一致）。
- 「标准问题」或「标准答案」为空的行**自动跳过**并提示，不影响其它行。
- 同一个文件里**重复的标准问题**只取第一条，其余提示忽略。

### 新增还是修改，怎么判断

机器人自动比对：

- 库里**没有** → 归入「新增」
- 库里**有**（问题名相同，或**高度相似**）→ 归入「修改」，只覆盖你填了的列
- 完全一样 → 归入「无变化」（不动）

> 💡 问题名略有差异也能识别为"修改"（模糊匹配兜底），避免重复新增。

### 指定目录

两种写法都行：

```
/import 软件/浩辰CAD许可配置 https://.../x.xlsx     ← 整批都归入这个目录
/import https://.../x.xlsx                          ← 目录取表格里的「类别/分组/三级目录」列
```

### 权限（和其他改动一致）

- **钟勇**：可导入任意目录。
- **目录负责人**：只能导入到**自己负责的目录**；表格里有条目不属于你 → **整批中止**，
  并列出越界的条目，让你修正后重试（不会半途导入一半）。

### 服务器上放了文件也可以用

若文件就在本机/共享盘，直接给路径：

```
/import D:\IT知识库\导入\浩辰新增.xlsx
/import \\文件服务器\共享\ERP更新.csv
```

> 单文件上限 **8MB**；链接需机器人所在机器**能访问到**（内网共享盘要求同一网络）。

## ❓ 常见问题

**Q：我改了 `data/kb.csv`（或覆盖安装），为什么机器人回答还是旧内容？**
A：**服务启动时会把 `kb.csv` 读进内存**，改文件后需要让它重新加载。本程序已内置**热更新**：
每次收到消息都会检查 `kb.csv` 的修改时间，一旦发现文件被改过就**自动重新加载**——
所以正常情况下**改完文件、下次提问即可生效，无需重启**。
若想立刻强制刷新，钟勇可发 **`/reload`**。
（前提是你确认服务进程**确实在跑**：用 `查看运行状态.bat` 看进程与日志。）

**Q：`errcode 853000 / invalid bot_id or secret`？**
A：凭据没被接受。① Secret 是否完整复制（点「复制」按钮，别框选）；
② 是否点过「重新生成」（旧的立即作废）；③ Bot ID 是否多位少位；
④ **复制后是否点了「保存」**；⑤ 机器人是否已启用。

**Q：`check.bat` 订阅成功但收不到消息？**
A：见上面「收不到消息」排查表，重点是**机器人是否启用 + 是否发给了对的机器人**。

**Q：Python 提示 "not found; run without arguments to install from the Microsoft Store"？**
A：那是 Windows 的假 `python.exe` 占位符。`install.bat` 已能识别并跳过它；
若仍失败，手动去 python.org 装 3.11 并**勾选 Add python.exe to PATH**。

**Q：Secret 泄露？**
A：企微后台重新生成 Secret，更新 `.env` 后重启。

**Q：员工说"已提交待审核"，但我（钟勇）没收到审批卡片？**
A：已修复。根因有两个：

1. **主动推送用错了标识** —— 企微 `aibot_send_msg` 要求用 **`chatid`（会话 id）**，
   而不是 `userid`。旧代码传的是 userid，企微拒收。
   现在机器人会在**钟勇每次发消息时记下他的 chatid**，推送时用它。
2. **推送失败却谎报成功** —— 旧代码不管推送成没成都回"已推送"。
   现在会**如实反馈**：失败时提示"审批提醒暂时没送达钟勇，
   建议直接联系他，或让他输入 /pending"。

> ⚠️ 前提：企微要求**对方先和机器人聊过**才能主动推送。
> 所以**钟勇必须先给机器人发过至少一条消息**（哪怕是"你好"），
> 否则第一次推送可能送不到。这是企微的限制，不是 bug。

**Q：我是钟勇，我自己改知识库，为什么还提示"等待审批"？**
A：**不该出现**。钟勇用 `/add`、`/edit`、`/del` 时是**立即生效**的，不生成审批单。
如果你看到"等待钟勇审批"，说明当时**你的企微身份不是 `ZhongYong`**
（比如用手机小号、或在别的企业账号下操作）。
用「我是谁」确认一下自己的账号。

**Q：电脑重启后机器人不工作了？**
A：那是没设自启。双击 `setup_autostart.bat` 即可，之后开机自动拉起。
用 `check_status.bat` 随时看它的状态。

**Q：`setup_autostart.bat` 报权限错误？**
A：右键它 →「以管理员身份运行」。多数机器不需要，个别策略严格的电脑需要。

**Q：怎么确认机器人现在活着？**
A：双击 `check_status.bat`，会显示计划任务状态、python 进程、
以及最近 12 行日志。或者直接去企微里发条消息试。

**Q：日志在哪？**
A：`logs\bot-YYYYMMDD.log`，按天分文件。服务模式下所有输出都在里面。

**Q：数据在哪？**
A：`data/kb.csv`、`data/pending.json`（待审）、`data/audit.json`（审计）。备份 `data/` 即可。

**Q：想换维护人？**
A：改 `.env` 的 `KB_MAINTAINER_ID` / `KB_MAINTAINER_NAME` 后重启。

**Q：为什么不能常驻输入框按钮？**
A：见上面「关于"输入框里的按钮"」——企微 API 模式机器人没有这个能力，
已用**进入会话自动推高频问题卡片**做等效替代。

**Q：答非所问 / 命中错条目？**
A：调 `app/kb_engine.py` 的匹配阈值（默认 `0.62`）。优化点时：
- 同主题反向意图（"卸载" vs "安装"）会被判为**意图冲突**直接压低分
- 问句带明确主题（如"打印机"）而条目主题完全不同时会被**主题否决**
- 兜底办法：给条目补「相似问法」，比调算法更有效

**Q：员工用别的叫法提问（如"欧特克CAD"、"Autodesk"）查不到？**
A：程序已经内置了同义词归一（`kb_engine.py` 的 `_TOPIC_SYNONYM`，
`欧特克`/`acad` → `autodesk`），并且 `data/kb.csv` 里 AutoDesk 各条目
已经补了「欧特克CAD怎么激活」「autodesk revit」「欧特克CAD卡顿」等别名。
**要加新叫法，最有效的做法是给对应条目补「相似问法」**，比如在
`/edit 欧特克` 里追加；光靠算法猜不出来新缩写。

**Q：机器人对"你好""我是钟勇"没反应？**
A：已修复。现在有身份识别：
- `我是谁` / `我的身份` / `whoami` → 核查企微身份，回复姓名/账号 + 该身份的权限
- 钟勇说「我是钟勇」→ 确认维护人身份 + 列出管理指令
- 别人说「我是钟勇」→ 明确纠正，引导走「提交」审批
- 任何人说「你好」→ 欢迎语 + 用法说明
- 带标点也认（`我是谁？`、`我是谁。` 都行）

**Q：怎么在聊天里维护/升级知识库？**
A：钟勇直接对话即可，**改完立即生效**：
- `/learn` 看待学习清单，`/learn <编号>` 补答案（知识库自己长）
- `/list 关键词` 找条目（带 id）
- `/edit <关键词或id>` 引导式修改（选字段 → 看当前值 → 改 → `0` 保存）
- `/add` 新增、`/del <关键词>` 删除
- 别人提交的走审批：机器人推卡片，点按钮即可

**Q：机器人会自己学新知识吗？**
A：会"记"，但不会自己"编答案"。员工问了答不上来的问题会被自动记录，
按热度排序进「待学习清单」；**答案必须由你给、并由你确认才入库**。
这样既能持续补全，又不会学到错误内容。

**Q：机器人对"我是谁？"（带问号）没反应？**
A：已修复。之前的判断是精确字符串比对，`我是谁？` 匹配不上。
现在用正则 + 标点剥离，`我是谁？`/`我是谁。`/`我的身份`/`whoami` 都能识别。
